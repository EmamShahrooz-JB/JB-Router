نصب خودکار JB-Router روی اکانت Cloudflare خودتان

توکن Cloudflare را وارد کنید؛ نصب روی همان اکانت انجام می‌شود — بدون CLI، بدون گیت‌هاب.
Cloudflare Workers API بدون ذخیره‌سازی توکن MIT
نکتهٔ فنی: API خودِ Cloudflare هدر CORS نمی‌دهد، پس مرورگر نمی‌تواند مستقیم به api.cloudflare.com وصل شود. این صفحه درخواست‌ها را به یک Worker واسط (jb-deployer) می‌فرستد که فقط و فقط با توکن خود شما با Cloudflare حرف می‌زند؛ توکن در هیچ دیتابیس/لاگی ذخیره نمی‌شود و فقط در همان لحظه برای همان درخواست استفاده می‌شود. کد این واسط باز است.
۱. مرورگر مرورگر شما توکن را می‌گیرد، دارایی‌ها را آماده و هش می‌کند.
۲. ورکر واسط درخواست‌ها را به Cloudflare می‌رساند (رفع محدودیت CORS).
۳. اکانت شما ورکر JB-Router + دارایی‌ها + Durable Object روی اکانت خودتان ساخته می‌شود.
۴. آماده آدرس <name>.<subdomain>.workers.dev تحویل داده می‌شود.

۱توکن Cloudflare

از My Profile → API Tokens ↗ قالب Edit Cloudflare Workers را بسازید (به Account.Workers Scripts: Edit، Account.Account Settings: Read و Account.Workers KV Storage: Edit نیاز داریم). توکن فقط روی اکانت همان حساب اثر دارد.

توکن در همین صفحه استفاده می‌شود و هیچ‌جا ذخیره/لاگ نمی‌شود. اگر نگران هستید، بعد از نصب توکن را از داشبورد Cloudflare باطل (Roll) کنید.

۲اکانت و نام ورکر

اگر اکانت شما هنوز subdomain ندارد، همین‌جا در فیلد بنویسید (مثلاً myname) تا ساخته شود. پیش‌نمایش آدرس نهایی: https://jb-router.<subdomain>.workers.dev

۳رمزهای اپلیکیشن

این‌ها به‌صورت Secret روی ورکرِ خودتان ذخیره می‌شوند؛ در URL یا لاگ هیچ‌جا چاپ نمی‌شوند.

چه چیزی نصب می‌شود؟

  • یک ورکر با نام دلخواه شما + دارایی‌های استاتیک (۱۰ مگابایت، ۴۲۸ فایل) و یک Durable Object با SQLite برای ذخیرهٔ تنظیمات، اتصال پروایدرها و لاگ مصرف.
  • دو Secret: JWT_SECRET و INITIAL_PASSWORD (همان‌هایی که بالاتر ساختیم).
  • آدرس /login برای داشبورد و /v1 به‌عنوان Endpoint سازگار با OpenAI برای کلاینت‌ها (Cursor، Cline، Claude Code، Codex و…).

توصیه: اکانت شما باید Workers Paid باشد، چون حجم اسکریپت JB-Router بیش از سقف پلن رایگان (۳ مگابایت) است. اگر پلن رایگان دارید، نصب با پیام خطای اندازه متوقف می‌شود. منبع و مستندات: EmamShahrooz-JB/JB-Router ↗
