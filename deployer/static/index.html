Install JB-Router efficiently

  1. Sign up a Cloudflare account and verify it.
  2. Create a token from the Workers template, then Continue to summary, Create Token and copy it.
  3. Paste it here, choose the installation type and install.
  4. After installation you own a JB-Router panel with URL, password and API endpoint.
